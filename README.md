# Netflix Audience Rating Classification

## Project Overview

This project focuses on predicting the **audience rating category** of Netflix content using machine learning classification techniques.

The objective is to prepare the Netflix dataset, train classification models, evaluate their performance, and generate predictions for audience rating categories.

## Objectives

* Analyze Netflix audience rating information.
* Prepare the dataset for classification.
* Perform data preprocessing.
* Train classification models.
* Evaluate model performance.
* Optimize the classification model.
* Generate audience rating predictions.
* Save the trained model and results.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Joblib

## Machine Learning Techniques

The project uses classification techniques such as:

* Decision Tree
* Random Forest
* Classification evaluation metrics
* Hyperparameter tuning

## Methodology

### 1. Data Preparation

The Netflix dataset is loaded and prepared for the classification task.

### 2. Data Preprocessing

The required features are processed and transformed into a suitable format for machine learning.

### 3. Model Training

Classification models are trained to predict the audience rating category of Netflix content.

### 4. Model Optimization

The classification models are optimized using appropriate machine learning techniques and hyperparameter tuning.

### 5. Model Evaluation

The trained models are evaluated using classification performance metrics to compare their prediction performance.

### 6. Prediction

The selected classification model is used to generate audience rating predictions for the Netflix content.

## Generated Files

The following files are generated:

* `netflix_rating_model_results.csv`
* `netflix_rating_classification_model.pkl`
* `netflix_rating_predictions.csv`

## File Description

* `netflix_rating_model_results.csv` – Contains the classification model results.
* `netflix_rating_classification_model.pkl` – Saved trained audience rating classification model.
* `netflix_rating_predictions.csv` – Contains the predicted audience rating categories.

## Results

The project trains and evaluates machine learning classification models for predicting Netflix audience rating categories. The model results and predictions are saved for further analysis.

## Conclusion

This project demonstrates how **machine learning classification techniques** can be applied to Netflix content data to predict audience rating categories and evaluate model performance.
